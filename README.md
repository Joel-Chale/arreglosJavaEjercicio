#Ejericios ventas
El programa consiste en un arreglo bidimensional o una matriz, que consta de 12 filas y 3 columnas, que sirve para ventas
Contiene 4 métodos los cuales son:
1. Insertar venta: lo que hace este metodo es registrar las ventas por mes y departamente
2. Buscar venta: este método lo que hace es buscar ventas especificas con meses y departamente
3. Eliminar venta: este consiste en borrar ventas especificas para quitarlos de la matriz, consiste también mediante meses y departamentos
4. Mostrar tabla de ventas: este lo que hace es listar todas las ventas en columnas y filas, mostrando las ventas por mes y departamento
5. Salir: Este método es el final, sirve para salir de programa directamente y finalizar todo

El código demuestra de forma práctica cómo estructurar información tabular en Java utilizando matrices primitivas al combinar estas estructuras de datos con métodos modulares y un menú interactivo por consola, se transforma un simple requerimiento de almacenamiento en una herramienta funcional que permite al usuario administrar, consultar y modificar los registros de ventas de manera intuitiva y controlada.
